# Dotabuff profile review

Use this guide when a player asks for analysis of their Dotabuff profile or shares a profile URL/player ID. Browse the public profile and relevant match pages when available. If browsing is unavailable, explain what the player can share for an analysis; do not claim to have inspected pages you could not access.

## Choose useful evidence

- Start with recent matches that match the player’s current goal. Prefer recent ranked games or the last few weeks for current habits; use lifetime hero/role data only as context. State the sample size and date range when visible.
- Review the profile Overview, Matches, and Heroes pages. Open Hero Mastery, Trends, Matchups, or individual match pages only when they answer a specific question.
- For relevant games, note the player’s hero, role/lane, match result, lane outcome, last hits, deaths, farm rate, item timing/build, and fight participation when those details are actually available.
- If the player names a focus hero or role, prioritize it. Otherwise, identify the strongest recent patterns across their active roles and heroes.

## Interpret carefully

- Separate observations shown by the site from coaching interpretations. Cite the profile and match pages used when browsing is available. Say when a value or detail is unavailable.
- Treat win rate, KDA, GPM, XPM, and other aggregates as clues, not proof of skill or cause. Account for sample size, role, match mode, party context, and patch changes. Avoid comparisons between unlike samples.
- Dotabuff data may be incomplete or stale. Do not describe it as live or fully current unless the page confirms a recent update. If recent matches are missing, mention that public match data may not be exposed or synced. The player can check Dota 2’s “Expose Public Match Data” setting and update/sync Dotabuff; do not imply that this restores historical matches that were never exposed. See [Dotabuff’s FAQ](https://www.dotabuff.com/pages/faq).

## Give actionable coaching

Structure an initial review around:

1. **Snapshot:** the sample, date range, main recent heroes/roles, and any notable limits in the data.
2. **Repeatable strength:** one habit supported by multiple relevant matches.
3. **Improvement opportunity:** one high-impact pattern with concrete evidence.
4. **Next-session goal:** one measurable action the player can practice in their next few games.

Use the selected role’s KPIs and decision priorities from the main skill and its role reference. Offer a deeper hero-by-hero or match-by-match review when useful.
