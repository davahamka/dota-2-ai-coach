# Patch intelligence: any hero and role

Read when the user asks about the current meta, ability changes, item builds, facets, objective timers, or before the first non-urgent patch-dependent answer in a coaching session.

## Verification sequence

1. Check **Valve** for the latest *released* gameplay patch: https://www.dota2.com/patches and https://www.dota2.com/news/updates/ . Search specific official announcements if dynamic pages have missing text. Record `patch`, `release_date`, `checked_at`, and source links. Check hotfixes and letter patches after the latest large patch.
2. Identify user's **selected hero + role** and any competing role builds. Find the appropriate page on https://dota2protracker.com/ or equivalent recent match statistics. Filter for position/role, same patch, date, sample size, and relevant MMR bracket when available. Do not substitute default Offlane data for a Carry hero or vice versa.
3. Confirm **game mechanics** from official patch notes or in-client tooltips: hero skills, innates, facets/talents, item effects, map layout, economy, neutral items, Roshan and other objective timings. Statistics suggest trends; they do not prove optimal item causation.
4. Review **role-specific** effects: a stat nerf may hurt laning; an item aura change may matter for position 3; vision/objective changes may matter for supports; tempo changes may matter for mid. Separate direct patch changes from your inferred strategic impact.
5. If no reliable same-patch match sample exists, say "provisional" and use verified mechanics plus stable principles. If verification fails entirely, clearly label `patch unverified` and avoid invented patch numbers, exact timers or unsupported talents.
6. Refresh if verification is >24 hours old, the user says a new patch has landed, or a client version conflicts. In live fights, answer immediately from known observations rather than delaying to research.

## Sources and interpretation

- Valve official notes = version and mechanical authority, not proof of best build.
- Dota 2 Pro Tracker = evidence on high-MMR role-specific items/skills in recent matches; check date, sample sizes and selection bias.
- Dotabuff, OpenDota, STRATZ, and user-provided replay/match IDs = secondary cross-checks; match region, bracket and time windows where possible.
- Current pick/win rates on one site do not imply superiority for the player's skill bracket; explain this distinction outside live calls.
- Distinguish `direct fact`, `observed meta pattern`, and `coach inference`. Cite source dates for factual claims about the current patch.

## Quick output outside match

**Verified version:** [patch] / [date checked] / [Valve source].
**Selected hero + position:** [important direct changes and lane implications].
**Current builds:** [role-filtered main line + situational alternative, source window/sample or 'provisional'].
**Macro changes:** [relevant map, objectives, timing or economy changes only].
**Practical adjustment:** [one thing to change next match].

Do not hard-code an eternal patch number or permanent WK/Spectre meta build into this reference. A skill alone does not check for patches in the background.
